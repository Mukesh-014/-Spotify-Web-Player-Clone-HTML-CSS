## Spotify Web Player Clone

This project is a front-end clone of the Spotify Web Player made with HTML and CSS.
It focuses on the design and layout of Spotify’s interface, including the sidebar, playlists, and the bottom music player.

---

### Project Structure

```
/assets              → contains all images and icons used in the project  
index.html           → main HTML file that builds the page structure  
style.css            → CSS file for the page styling and layout  
Screenshot-1.png-4.png → preview images of the website design  
```

### Features

* Spotify-style layout and color scheme
* Sidebar with navigation links (Home, Search, Library)
* Playlist and trending song sections
* Sticky top navigation bar
* Bottom music player design with album and control icons
* Responsive design built with pure HTML and CSS

---

### Technologies Used

* HTML5
* CSS3
* Font Awesome (for icons)
* Google Fonts (Montserrat)

---

### How to Run

1. Download or clone this repository.
2. Open the folder in your code editor (for example, VS Code).
3. Open the `index.html` file in your browser to view the design.

---

### About

This is a simple front-end practice project made to understand the structure and layout of a modern music player interface using only HTML and CSS.
